# 🔹 Project 1 – Sales Dashboard Analysis

### 🎯 Objective

Analyze sales performance by region, product category, product, and time
period and create a dashboard that helps management understand revenue
performance.

### 🔍 Analysis

- Total Revenue
- Monthly Revenue Trend
- Regional Performance
- Category Performance
- Top-Selling Products
- Average Order Value

- Data Cleaning
- KPI Creation
- Pivot Tables
- Data Visualization
- Dashboard Design
- Business Insights
